# Macro Placement Research Atlas

宏布局研究图谱：[打开网站](https://pc666.github.io/macro-research-atlas/)。

本项目按具体出版版本、研究任务和方法组件组织宏布局文献，并为每条关系保留可定位的原始来源。

“原文方法核查”表示核对了条目中所写的方法及定位，不表示完成算法复现或独立验证性能。摘要级条目只陈述摘要及其附列证据支持的内容。

## 数据组织

可编辑数据为 [`data/atlas.json`](data/atlas.json)。

- `papers`：本次核查记录。每条包含具体版本、主任务、方法、六类组件、适用范围和逐条证据。
- `relations`：关系独立记录类型、起终点、采用组件、来源、定位和限制。
- `pending`：待核查题录。旧版方法说明、混合分类和 A/B 等级不在此集合中沿用。
- `comparison`：TVLSI 2021 与 DATE 2025 的逐阶段对读、原表数值及实验配置说明。
- `revision`：本次修订记录。

主任务包括基础几何表示、宏布局、混合尺寸/全局布局、需求估计/候选评价、全局布线和工程文档。方法组件包括几何表示、连接关系、区域与面积分配、优化与搜索、几何合法化、评价与验证。这些组件可同时出现在同一篇论文中。

### 关系类型与方向

| 类型 | 含义 | 方向 | 图中显示 |
| --- | --- | --- | --- |
| `adopts` | 明确采用某个方法组件或实现 | 组件来源 → 使用它的工作 | 是 |
| `extends` | 原文明确声明版本扩展 | 前版 → 后版 | 是 |
| `compares` | 目标论文报告对比实验 | baseline / 被比较工作 → 报告对比的工作 | 仅证据表，以“与”连接 |
| `cites` | 目标论文存在可定位引用 | 被引用文献 → 引用文献 | 仅证据表；不表示技术继承 |

采用关系写明具体组件。使用软件时同时标注实际软件版本与引用的论文版本；二者不能互相代替。共同作者、机构或年份先后不构成采用或扩展证据。

### 日期与出版版本

`year` 指当前记录的具体出版物年份。会议版、期刊版与预印本分别标识；在线发表年份和卷期年份在版本说明中区分。Re²MaP 的方法说明锚定 2025 年 arXiv v1，后续期刊出版状态独立记录。持续更新的实现文档使用 `year: null` 和核对日期。

## 构建

只需 Python 3，无第三方包：

```sh
python3 build.py
```

构建程序校验文献 ID、关系端点和必需证据字段，将以下源码与数据嵌入一个可独立打开的 `index.html`：

- `src/template.html`：页面结构
- `src/styles.css`：响应式样式
- `src/app.js`：筛选、关系图、详情与本地阅读记录
- `data/atlas.json`：研究数据

GitHub Pages 从主分支提供静态页面。修改源数据或页面源码后，应重新构建 `index.html`，再一起提交。页面不依赖外部脚本、CDN 或分析服务。
